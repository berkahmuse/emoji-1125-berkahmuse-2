## The glyph

A compass. The agent takes a task, orients itself in unfamiliar territory,
charts a course through whatever it finds, and keeps going until it arrives —
no map handed to it, no rails to follow. One familiar shape, readable at any
size: an agent that explores, orients, and delivers. Not a robot, not a smile —
a working instrument for an agent that works alone in the open.

## Run

```sh
node main.ts
```

Writes exactly one emoji to `/output/entry.txt` (no trailing newline).
Deterministic: running it twice produces byte-identical output.
